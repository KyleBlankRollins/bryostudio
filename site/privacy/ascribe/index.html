Ascribe privacy policy

Effective and last updated: 20 October 2026

In short: Ascribe collects nothing. It has no telemetry, no crash reports and no account, calls no AI service, and sends nothing to Bryo Studio. It reaches the network only when you run something that needs it, and only to the services you point it at.

This policy covers Ascribe, made by Bryo Studio (“we”, “us”): the ascribe command, the Ascribe extension for VS Code, the @ascribed packages on npm, and the website ascribed-dev.com. The Bryo Studio privacy policy covers this website.

What leaves your computer

Ascribe reads your project’s files and answers on your computer. These are the only things that send anything anywhere, and each happens only when you do it:

When Ascribe reaches the network
When you What is sent To whom
Review a pull request, in VS Code or the site preview The pull request’s comment threads are read, and the comments you write are posted, signed in as you GitHub
Run ascribe sources fetch or update A git fetch of the repositories your project’s ascribe.toml names Wherever those repositories are hosted
Run ascribe report links A request to each external link in your docs, made by lychee, a link checker you install The sites your docs link to
Run ascribe report agents Requests to your published site, made by afdocs, a checker you install Your site’s host
Run ascribe observe Whatever your project’s own test commands send; Ascribe runs them and sends nothing itself Your tests decide
Install or update Ascribe The download npm, Homebrew, GitHub or the VS Code Marketplace, under their own policies

AI assistants and agents

Ascribe calls no AI model and holds no key for one. When you use an AI coding agent with Ascribe, what Ascribe tells the agent, such as a page’s text or a list of problems, becomes part of what that agent sends to its model, as any file it reads does, under the agent’s own terms. A prompt Ascribe writes for your agent stays on your computer until you send it.

Ascribe’s documentation says more in What’s sent where.

The website

ascribed-dev.com sets no cookies and runs no analytics or tracking. It is hosted by Netlify, whose servers, like any web server, see your IP address and browser details when you visit, and keep short-lived logs for running the service and keeping it secure. We do not use these logs to identify visitors.
